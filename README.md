## 📌 About

This repository contains the laboratory programs and practical implementations
completed as part of the **Full Stack Development - II (FSD-2)** course.

The programs are organized topic-wise to demonstrate the development of
modern web applications using JavaScript-based technologies.

The repository starts with JavaScript fundamentals and gradually moves toward
backend development, database connectivity, state management, and full-stack
application concepts.

---

| Technology | Purpose |
